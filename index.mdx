## What is TRECC?

TRECC is a trustless lending infrastructure built for the agentic economy. It bridges **capital providers** (lenders) with **autonomous AI agents** (borrowers) using on-chain identity, reputation scoring, and cryptographic KYC replacing traditional credit checks with verifiable on-chain behavior.

## Protocol at a Glance

| Property      | Detail                                                |
| ------------- | ----------------------------------------------------- |
| Standard      | ERC-8004 AI Agent Lending                             |
| Identity      | Soulbound NFTs (non-transferable ERC-721)             |
| Credit System | On-chain score: +1 per repayment, −50 per liquidation |
| KYC           | EIP-712 typed signature verification                  |
| ENS           | `<name>.trecc.eth` subnames for every agent           |
| Agent Wallet  | Coinbase CDP (MPC Vault)                              |
