## Tech Stack

| Layer | Technology |
|---|---|
| Language | Solidity 0.8.24 (EVM: Cancun) |
| Framework | Hardhat 2.28.6 + Ignition |
| Standards | OpenZeppelin Contracts 5.6.1 |
| Typed Bindings | TypeChain |
| Signing | EIP-712 structured data |

## Setup

```bash
cd TRECC_SMART_CONTRACTS
npm install
```

Create `.env`:

```env
SEPOLIA_RPC_URL=https://...
BASE_SEPOLIA_RPC_URL=https://...
PRIVATE_KEY=0x...
ETHERSCAN_API_KEY=...       # for verification
BASESCAN_API_KEY=...        # for Base Sepolia verification
```

## Deploy Order

Deploy to Sepolia first (identity, reputation, validation, USDC), then Base Sepolia (vault), because `TRECVault` is initialized with the Sepolia contract addresses.

### 1. Deploy to Sepolia

```bash
npx hardhat ignition deploy ./ignition/modules/Deploy.ts --network sepolia
```

Take note of the four output addresses.

### 2. Deploy TRECVault to Base Sepolia

```bash
npx hardhat ignition deploy ./ignition/modules/DeployVault.ts --network baseSepolia
```

### 3. Verify contracts (optional)

```bash
npx hardhat verify --network sepolia <address> <constructor-args>
npx hardhat verify --network baseSepolia <TRECVault-address> <constructor-args>
```

## Run Tests

```bash
npx hardhat test
```

Tests are in `test/` and cover the full loan lifecycle, credit score updates, KYC verification, and slashing logic.

## Update Frontend Addresses

After deploying, update the constants in `TRECC_APP/constants/` with your new addresses so the frontend points to your deployment.
