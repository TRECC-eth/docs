---
title: "Contract Deployment"
description: "Deploy TRECC contracts to your own testnet environment"
---

## Prerequisites

- Node.js 18+
- A funded Sepolia wallet (for gas)
- A funded Base Sepolia wallet (for gas)
- Sepolia and Base Sepolia RPC URLs

## Setup

```bash
cd TRECC_SMART_CONTRACTS
npm install
```

Create a `.env` in `TRECC_SMART_CONTRACTS/`:

```env
SEPOLIA_RPC_URL=https://...
BASE_SEPOLIA_RPC_URL=https://...
PRIVATE_KEY=0x...
```

## Deploy to Sepolia

```bash
npx hardhat ignition deploy ./ignition/modules/Deploy.ts --network sepolia
```

This deploys `MockUSDC`, `TRECIdentityRegistry`, `TRECReputationRegistry`, and `TRECValidationRegistry`.

## Deploy to Base Sepolia

```bash
npx hardhat ignition deploy ./ignition/modules/DeployVault.ts --network baseSepolia
```

This deploys `TRECVault`, wired to the Sepolia contract addresses from the previous step.

## Run Tests

```bash
npx hardhat test
```

Tests use Hardhat's in-process network. See `test/` for full coverage of all contract interactions.

<Note>
  After deploying your own contracts, update the addresses in `TRECC_APP/constants/` before running the frontend.
</Note>
