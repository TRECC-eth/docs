## Dependency Map

`TRECVault` is the central coordinator. It reads from and writes to the three registry contracts:

```mermaid

  V["TRECVault"]
  IR["TRECIdentityRegistry"]
  RR["TRECReputationRegistry"]
  VR["TRECValidationRegistry"]
  U["MockUSDC"]

  V -- "reads agentId" --> IR
  V -- "records activity" --> RR
  V -- "checks KYC" --> VR
  V -- "transfers liquidity" --> U

  class V vault
  class IR,RR,VR registry
  class U token
```
